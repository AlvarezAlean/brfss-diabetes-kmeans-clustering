# Segmentación de Perfiles de Salud y Estilo de Vida (BRFSS 2015 - K-Means)

Proyecto de Minería de Datos basado en el conjunto de datos **CDC Diabetes Health Indicators (BRFSS 2015)**, aplicando escalamiento con StandardScaler y agrupamiento con **K-Means** (k=3).

## Archivos principales
- Cuadernos de trabajo (.ipynb) con exploración, limpieza, evaluación de k, entrenamiento y exportación.
- pp.py: aplicación interactiva en Streamlit conectada a scaler_kmeans.joblib y modelo_kmeans.joblib.
- scaler_kmeans.joblib y modelo_kmeans.joblib: escalador y modelo K-Means entrenados.
- equirements.txt: dependencias de Python del proyecto.

> **Aviso académico:** Este proyecto tiene fines exclusivamente académicos e ilustrativos y no constituye un diagnóstico médico ni sustituye la valoración de un profesional de la salud.
